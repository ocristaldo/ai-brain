# Idea: Automated Meeting Summarization

Use AI to automatically summarize meetings and extract action items.

## Concept
- Record meetings with permission
- Transcribe using Whisper
- Summarize with Claude
- Extract action items automatically
- Send to team Slack channel

## Benefits
- Save time on note-taking
- Never miss action items
- Searchable meeting history
